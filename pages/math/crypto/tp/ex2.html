2.1. Algorithme d'Euclide et remontée de Bézout pour 3315 et 154

2.2. Inversibilité dans l'anneau $\mathbb{Z}/3315\mathbb{Z}$

  • Justification : Un élément $a$ est inversible dans $\mathbb{Z}/n\mathbb{Z}$ si et seulement si $\operatorname{pgcd}(a, n) = 1$. Comme on a montré à la question précédente que $\operatorname{pgcd}(3315, 154) = 1$, 154 est bien inversible dans $\mathbb{Z}/3315\mathbb{Z}$.
  • Calcul détaillé de l'inverse :
    À la question 2.1, nous avons obtenu l'identité de Bézout : $$3315 \times (-19) + 154 \times 409 = 1$$ Passons cette égalité **modulo $3315$** :
    1. Le terme $3315 \times (-19)$ est un multiple de $3315$, donc $3315 \times (-19) \equiv 0 \pmod{3315}$.
    2. L'égalité devient alors : $$0 + 154 \times 409 \equiv 1 \pmod{3315}$$
    3. Soit encore : $$154 \times 409 \equiv 1 \pmod{3315}$$
    Par définition de l'inverse modulaire ($a \times a^{-1} \equiv 1 \pmod n$), l'inverse de $154$ modulo $3315$ est donc **$409$** (ou sa classe $[409]_{3315}$).
  • Tous les éléments non nuls sont-ils inversibles ? Non. Un élément $x \in \mathbb{Z}/3315\mathbb{Z}$ n'est inversible que si $\operatorname{pgcd}(x, 3315) = 1$.
    Or, $3315$ n'est pas un nombre premier ($3315 = 3 \times 5 \times 13 \times 17$).
    Par exemple, le nombre $3$ n'est pas nul dans $\mathbb{Z}/3315\mathbb{Z}$, mais $\operatorname{pgcd}(3, 3315) = 3 \neq 1$ : il n'admet donc aucun inverse modulaire. Tous les éléments non nuls ne sont donc pas inversibles.

2.3. Résolution de l'équation de congruence

  • Le problème : Trouver le plus petit entier naturel $n$ tel que : $$n \times 154 \equiv 1533 \pmod{3315}$$
  • Résolution : On multiplie les deux membres par l'inverse de $154$ (qui est $409$) : $$n \equiv 1533 \times 409 \pmod{3315}$$ $$n \equiv 626997 \pmod{3315}$$
  • Division euclidienne : $626997 = 189 \times 3315 + 462$.
  • Conclusion : Le plus petit entier naturel recherché est $n = 462$.

2.4. Algorithme d'Euclide étendu en Python

  • Consigne : Écrire une fonction prenant deux entiers $a$ et $b$ et renvoyant le triplet $(d, u, v)$ tel que $au + bv = d = \operatorname{pgcd}(a, b)$.
  • Code Python : 
    def euclide_etendu(a:int, b:int):
    r0, r1 = a, b
    u0, u1 = 1, 0
    v0, v1 = 0, 1
    while r1 != 0:
        q = r0 // r1
        r0, r1 = r1, r0 - q * r1
        u0, u1 = u1, u0 - q * u1
        v0, v1 = v1, v0 - q * v1
    return r0, u0, v0

d, u, v = euclide_etendu(3315, 154)
print(f"PGCD = {d}, u = {u}, v = {v}")
# Résultat : PGCD = 1, u = -19, v = 409

Premiers entre eux

Deux entiers $a$ et $b$ sont premiers entre eux si leur plus grand diviseur commun vaut 1 : $\operatorname{pgcd}(a, b) = 1$.

Inverse modulaire ($a^{-1}$)

Un entier $x$ tel que $ax \equiv 1 \pmod{n}$. Il existe si et seulement si $a$ et $n$ sont premiers entre eux.

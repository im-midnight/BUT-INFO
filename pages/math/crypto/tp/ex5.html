Exercice 5 : Problème du logarithme discret

Passe la souris surTouche les termes soulignés en bleu pour afficher leur définition.

Principe général

On travaille dans le groupe multiplicatif $(\mathbb{Z}/p\mathbb{Z})^*$, où $p$ est un nombre premier. Ses éléments sont les classes non nulles modulo $p$ :

$$ (\mathbb{Z}/p\mathbb{Z})^* = \{1,2,\ldots,p-1\} $$

Ce groupe contient donc $p-1$ éléments. On cherche un générateur $g$ : ses puissances modulo $p$ permettent d'obtenir tous les éléments non nuls.

Le problème du logarithme discret consiste à retrouver l'exposant $x$ connaissant $g$, $y$ et $p$ :

$$ g^x \equiv y \pmod p $$
Lien avec le cours : dans le contexte de Diffie-Hellman, on sait facilement calculer $g^x \bmod p$ lorsque $x$ est connu. Le problème étudié ici est l'opération inverse : retrouver $x$ à partir de $g^x \bmod p$.

5.1. Trouver un générateur aléatoire de $(\mathbb{Z}/p\mathbb{Z})^*$

Objectif : choisir un entier au hasard, vérifier s'il est générateur et recommencer tant que ce n'est pas le cas.

Critère vu dans le cours : pour un nombre premier $p$, un élément $g$ est générateur de $(\mathbb{Z}/p\mathbb{Z})^*$ si et seulement si :

$$ g^k \not\equiv 1 \pmod p \quad \text{pour tout } k \in \{1,2,\ldots,p-2\}. $$

Pourquoi ce critère fonctionne :

  • Si deux puissances $g^a$ et $g^b$, avec $0 \leq a < b \leq p-2$, étaient égales, alors on aurait $g^{b-a} \equiv 1 \pmod p$.
  • Or $1 \leq b-a \leq p-2$. Le critère interdit cette égalité.
  • Les $p-1$ puissances $g^0,g^1,\ldots,g^{p-2}$ sont donc toutes différentes. Comme le groupe contient exactement $p-1$ éléments, elles le parcourent entièrement.

Code Python :

import random

def generateur(p):
    while True:
        g = random.randint(2, p - 1)
        est_generateur = True

        k = 1
        while k <= p - 2:
            if (g**k % p)== 1:
                est_generateur = False
                break
            k += 1

        if est_generateur:
            return g

5.2. Fonction log_discret(y, g, p)

Objectif : trouver un entier $x$ tel que :

$$ g^x \equiv y \pmod p $$

Comme $g$ est un générateur, les puissances $g^0,g^1,\ldots,g^{p-2}$ parcourent tous les éléments non nuls. Il suffit donc de tester ces exposants dans l'ordre.

Code Python :

def log_discret(y, g, p):
    x = 0
    while x <= p - 2:
        if (g**x % p) == y:
            return x
        x += 1
    return None

Exemple : avec $p=43$, $g=3$ et $y=11$, on cherche $x$ tel que $3^x \equiv 11 \pmod{43}$.

print(log_discret(11, 3, 43))

5.3. Algorithme de Shanks : pas de bébé, pas de géant

L'objectif est toujours de résoudre $g^x \equiv y \pmod p$, mais en évitant de tester tous les exposants un par un.

1. Découper l'exposant

On pose :

$$ s = 1 + \lfloor\sqrt{p}\rfloor $$

On cherche à écrire l'exposant sous la forme :

$$ x = r_0 + k_0s $$

avec $0 \leq r_0 < s$ et $0 \leq k_0 < s$.

2. Calculer les pas de bébé

On construit la première liste avec les premières puissances de $g$ :

$$ L_1 = [1, g, g^2, g^3, \ldots, g^{s-1}] \pmod p $$

Chaque élément de cette liste correspond à $g^{r_0}$.

3. Calculer les pas de géant

On calcule d'abord l'inverse modulaire de $g^s$ :

$$ g^{-s} \equiv (g^s)^{-1} \pmod p $$

Puis on construit :

$$ L_2 = [y,\; yg^{-s},\; yg^{-2s},\; \ldots,\; yg^{-(s-1)s}] \pmod p $$

Chaque élément correspond à $y \cdot (g^{-s})^{k_0}$.

4. Trouver une valeur commune

On cherche une occurrence commune aux deux listes. Si :

$$ g^{r_0} \equiv y \cdot g^{-k_0s} \pmod p $$

alors, en multipliant par $g^{k_0s}$ :

$$ g^{r_0+k_0s} \equiv y \pmod p $$

On obtient donc une solution :

$$ \boxed{x = r_0 + k_0s} $$

Code Python

import math

def inverse_modulaire(a, p):
    a = a % p
    for i in range(1, p):
        if (a * i) % p == 1:
            return i
    return None

def bsgs(g,y,p):
    s = 1 + math.floor(math.sqrt(p))

    l1=[g**i % p for i in range(s)]

    gs = (g**s) % p
    gs_inv = inverse_modulaire(gs, p)
    l2 = [(y * (gs_inv**i)) % p for i in range(s)]

    print("l1 :" ,l1)
    print("l2 :" ,l2)

    for r0 in range(s):
        if l1[r0] in l2:
            k0 = l2.index(l1[r0])
            return r0 + k0 * s
    return None

Exemple détaillé : bsgs(3, 11, 43)

On cherche $x$ tel que $3^x \equiv 11 \pmod{43}$.

  1. Calcul de $s$ : $s = 1 + \lfloor\sqrt{43}\rfloor = 7$.
  2. Liste des pas de bébé :
$$ L_1 = [1,3,9,27,38,28,41] $$
  1. Calcul de l'inverse : $3^7 \equiv 37 \pmod{43}$ et $37^{-1} \equiv 7 \pmod{43}$, car $37 \times 7 \equiv 1 \pmod{43}$.
  2. Liste des pas de géant :
$$ L_2 = [11,34,23,32,9,20,11] $$

Valeur commune : $9$ apparaît dans $L_1$ à l'indice $r_0=2$ et dans $L_2$ à l'indice $k_0=4$ (les indices commencent à $0$).

$$ x = r_0 + k_0s = 2 + 4 \times 7 = \boxed{30} $$

Vérification :

$$ 3^{30} \equiv 11 \pmod{43} $$ 
print(bsgs(3, 11, 43))
# Résultat : 30

Synthèse de l'exercice

Question Fonction Idée principale
5.1 generateur(p) Tirer un candidat au hasard et vérifier que $g^k \not\equiv 1 \pmod p$ pour $1 \leq k \leq p-2$.
5.2 log_discret(y, g, p) Tester les exposants $x$ jusqu'à trouver $g^x \equiv y \pmod p$.
5.3 bsgs(g, y, p) Construire deux listes et trouver une valeur commune pour obtenir $x=r_0+k_0s$.
À retenir : la question 5.2 recherche le logarithme discret par essais successifs. La question 5.3 utilise l'algorithme de Shanks pour réduire le nombre de recherches en séparant le calcul en deux listes d'environ $\sqrt p$ éléments.

Générateur

Un élément $g$ est un générateur de $(\mathbb{Z}/p\mathbb{Z})^*$ si ses puissances $g^0,g^1,\ldots,g^{p-2}$ donnent tous les éléments non nuls modulo $p$.

Groupe multiplicatif $(\mathbb{Z}/p\mathbb{Z})^*$

Il s'agit des classes non nulles modulo $p$, munies de la multiplication modulo $p$. Lorsque $p$ est premier, ce groupe contient $p-1$ éléments.

Logarithme discret

Étant donnés un générateur $g$, un nombre premier $p$ et un élément $y$, trouver $x$ tel que $g^x \equiv y \pmod p$. Le calcul direct de la puissance est simple ; retrouver l'exposant peut être beaucoup plus difficile lorsque $p$ est grand.

Inverse modulaire

L'inverse de $a$ modulo $p$ est un entier $u$ tel que $a \times u \equiv 1 \pmod p$. Il existe lorsque $a$ et $p$ sont premiers entre eux.

Pas de bébé

La liste des pas de bébé contient les petites puissances $g^0,g^1,\ldots,g^{s-1}$ modulo $p$. Elle permet de retrouver la partie $r_0$ de l'exposant.

Pas de géant

La liste des pas de géant contient $y$ multiplié successivement par $g^{-s}$. Elle permet de retrouver la partie $k_0$ de l'exposant.

Exponentiation modulaire

pow(a, b, p) renvoie $a^b \bmod p$ en effectuant le calcul de manière efficace sans construire inutilement le très grand entier $a^b$.

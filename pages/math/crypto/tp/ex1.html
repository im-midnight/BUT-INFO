1. Question 1.1 - Le test de primalité et la borne $\sqrt{n}$

  • Objectif : Démontrer que si un nombre $n$ n'est pas premier, son plus petit diviseur strict est inférieur ou égal à $\sqrt{n}$, puis implémenter un test en Python.
  • Démonstration : Soit $n = a \times b$ avec $1 < a \le b < n$. Si $a > \sqrt{n}$ et $b > \sqrt{n}$, alors leur produit $a \times b > \sqrt{n} \times \sqrt{n} = n$, ce qui est absurde. Par conséquent, l'un au moins des facteurs $a$ ou $b$ (le plus petit diviseur) doit nécessairement vérifier $\le \sqrt{n}$.
  • Implémentation Python (`est_premier`) : 
    def est_premier(n: int) -> bool:
    div = 2
    if n == 0 or n == 1:
        return False
    while div * div <= n:
        if n % div == 0:
            return False
        div += 1
    return True
  • Indicateur : Complexité temporelle en $O(\sqrt{n})$ pour tester un nombre unique.

  • Code du Crible d'Ératosthène : 
    def crible(n):
    premiers = []
    tab = [True] * (n + 1)
    tab[0] = tab[1] = False
    for i in range(2, n + 1):
        if tab[i]:
            premiers.append(i)
            multiple = i * i
            while multiple <= n:
                tab[multiple] = False
                multiple += i
    return premiers

Synthèse des Méthodes

Fonction Rôle principal Complexité / Limite
est_premier(n) Teste si un entier $n$ est premier $O(\sqrt{n})$ - Très efficace pour un grand $n$ isolé.
crible(n) Génère tous les premiers $\le n$ $O(n \log \log n)$ - Limité par la mémoire RAM pour $n > 10^8$.
comparaison(n) Compare $len(n)/n$ à $\frac{1}{\ln(n)}$ Illustre la raréfaction logarithmique.

Nombre Premier

Un entier naturel strictement supérieur à 1 qui n'admet que deux diviseurs distincts : 1 et lui-même (ex : 2, 3, 5, 7, 11...).

Complexité Algorithmique ($\sqrt{n}$)

Mesure le nombre d'opérations nécessaires. En s'arrêtant à $\sqrt{n}$, on réduit drastiquement le nombre de divisions de $n$ (linéaire) à $\sqrt{n}$ (sous-linéaire).

Crible d'Ératosthène

Algorithme antique permettant de trouver tous les nombres premiers inférieurs à un entier donné en barrant (éliminant) les multiples successifs de chaque nombre premier.

Théorème des Nombres Premiers

Établit que la proportion de nombres premiers inférieurs à $n$ est approximativement inversement proportionnelle à son logarithme népérien : $\frac{1}{\ln(n)}$.

Raréfaction

Phénomène par lequel les nombres premiers se font de plus en plus rares à mesure que l'on progresse vers l'infini, bien qu'il en existe une infinité.

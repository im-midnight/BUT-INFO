Exercice 7 : Code de Hamming, méthode sur papier

Passe la souris surTouche les termes soulignés en bleu pour afficher leur définition.

Principe général (rappel du cours)

  • Positions : on numérote les bits à partir de $1$ en partant de la gauche. Les bits de parité $p_1, p_2, p_4, p_8, \ldots$ occupent les positions qui sont des puissances de $2$ ; les bits du message occupent toutes les autres positions.
  • Nombre de bits de parité : pour un message de $m$ bits, on prend le plus petit $k$ tel que $2^k \geq m + k + 1$. Le code a alors $n = m + k$ bits. $$ k = 2 \Rightarrow (n, m) = (3, 1) \qquad k = 3 \Rightarrow (7, 4) \qquad k = 4 \Rightarrow (15, 11) $$
  • Calcul des bits de parité : on écrit en binaire la position de chaque bit à $1$ du message, puis on additionne chaque colonne ($2^0, 2^1, 2^2, \ldots$) modulo $2$. Le résultat de la colonne $2^i$ donne le bit de parité placé à la position $2^i$ (parité paire).
  • Contrôle à la réception : on refait la même somme sur tous les bits à $1$ du mot reçu, bits de parité compris. Le résultat s'appelle le syndrome : s'il vaut $0000$, aucune erreur n'est détectée ; sinon, en supposant au plus une erreur, sa valeur lue en binaire est la position du bit faux.

7.1 Ajouter les bits de parité au message

Message à transmettre : 0 1 1 0 1 1 0 0 1 0, donc $m = 10$ bits.

Étape 1 : nombre de bits de parité

Avec $k = 3$ on a $2^3 = 8 < 10 + 3 + 1 = 14$ : insuffisant. Avec $k = 4$ on a $2^4 = 16 \geq 10 + 4 + 1 = 15$ : convient (un code de Hamming $(15, 11)$ raccourci). On ajoute donc 4 bits de parité en positions $1, 2, 4, 8$ et le code fait $n = 14$ bits.

7.2 Analyser un message reçu

Mot reçu : 1 0 1 1 0 0 1 0 0 0, donc $n = 10$ bits. Les puissances de $2$ inférieures ou égales à $10$ sont $1, 2, 4, 8$ : il y a 4 bits de parité et donc $m = 10 - 4 = 6$ bits d'information (positions $3, 5, 6, 7, 9, 10$).

Conclusion

  • Le syndrome est non nul : le message reçu contient une erreur.
  • Seule la colonne $2^0$ est fausse, donc la position erronée vaut $1 \times 2^0 = 1$ : c'est le bit de parité $p_1$.
  • Mot corrigé : 0 0 1 1 0 0 1 0 0 0 (on vérifie : $b_3, p_4, b_7$ donnent des colonnes de somme $2, 2, 2, 0$, donc un syndrome nul).
  • L'erreur porte sur un bit de parité : les bits d'information $b_3, b_5, b_6, b_7, b_9, b_{10}$ sont intacts. Le message d'origine est 1 0 0 1 0 0.
Limite : cette conclusion suppose qu'il y a au plus une erreur. Avec deux erreurs (ou plus), le syndrome est non nul mais pointe vers une mauvaise position (ou une position hors du mot) : l'erreur est détectée mais la correction est fausse.

Synthèse des notions clés

Notion / OutilRôle / Définition principaleExpression / Formule clé
Bits de parité Placés aux positions $1, 2, 4, 8, \ldots$ ; ils rendent la somme de chaque colonne paire $p_{2^i} = \sum b_j \bmod 2$ pour les $j$ dont le chiffre $2^i$ vaut $1$
Taille du code $k$ bits de parité pour $m$ bits de message $2^k \geq m + k + 1$, $n = m + k$ ($\leq 2^k - 1$)
Syndrome Somme modulo 2 des positions (en binaire) des bits à $1$ du mot reçu $0000$ : pas d'erreur ; sinon position de l'erreur $= \sum y_i\,2^i$
Limite Corrige une erreur, ne peut pas corriger correctement deux erreurs distance minimale $d_H = 3$
À retenir : à l'émission on calcule les bits de parité pour que le syndrome soit nul ; à la réception on recalcule le syndrome, et sa valeur en binaire donne directement la position du bit à corriger.

Bit de parité

Bit ajouté au message pour que la somme d'un groupe de bits soit paire (parité paire) : $0$ si le nombre de $1$ du groupe est pair, $1$ s'il est impair. Dans le code de Hamming, chaque bit de parité contrôle un groupe de positions différent.

Syndrome

Résultat du contrôle de parité effectué à la réception sur tous les bits du mot. Nul si aucune erreur n'est détectée ; sinon, pour une erreur unique, sa valeur en binaire est la position du bit erroné.

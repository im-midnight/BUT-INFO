4.1. Dictionnaire de correspondance dans $\mathbb{Z}/31\mathbb{Z}$

  • Principe : On travaille dans l'anneau $\mathbb{Z}/31\mathbb{Z}$ (31 éléments numérotés de $0$ à $30$). Les lettres de l'alphabet occupent les positions $1$ à $26$, suivies de $4$ caractères spéciaux (positions $27$ à $30$), et la 31e position associée au caractère ':' prend la valeur $0$.
  • Code Python : 
    # Dictionnaire caractère -> valeur dans Z/31Z
dico = {chr(64 + i): i for i in range(1, 31)}
dico[':'] = 0

# Dictionnaire inverse : valeur dans Z/31Z -> caractère
dico_inverse = {valeur: cle for cle, valeur in dico.items()}

print(dico)
print(dico_inverse)
  • Aperçu des correspondances générées :
    Caractère ':' 'A' 'B' 'C' $\dots$ 'Z' '[' '\' ']' '^'
    Valeur dans $\mathbb{Z}/31\mathbb{Z}$ $0$ $1$ $2$ $3$ $\dots$ $26$ $27$ $28$ $29$ $30$
    Remarque : Avec chr(64 + i) pour $i \in \{1, \dots, 30\}$, les indices $1$ à $26$ donnent bien 'A' à 'Z' (codes ASCII 65 à 90), et les indices $27$ à $30$ donnent les caractères ASCII suivants ('[', '\', ']', '^')

4.2. Fonction de chiffrement chiff_affine(mess, a, b)

  • Formule mathématique : Pour chaque caractère $c$ du message, on calcule sa nouvelle position $y$ via la transformation affine : $$y \equiv a \times position(caractere) + b \pmod{31}$$
  • Code Python : 
    def chiff_affine(mess, a, b):
    res = ""
    for c in mess:
        if c in dico.keys():
            position = dico[c]
            newIndice = (a * position + b) % 31
            res += dico_inverse[newIndice]
    return res

message1 = "ABCD"
print(chiff_affine(message1, 2, 1))  # Affiche "CEGI"
  • Exemple pas à pas (avec $a = 2$, $b = 1$ sur "ABCD") :
    • 'A' ($x = 1$) $\longrightarrow (2 \times 1 + 1) \bmod 31 = 3 \longrightarrow$ 'C'
    • 'B' ($x = 2$) $\longrightarrow (2 \times 2 + 1) \bmod 31 = 5 \longrightarrow$ 'E'
    • 'C' ($x = 3$) $\longrightarrow (2 \times 3 + 1) \bmod 31 = 7 \longrightarrow$ 'G'
    • 'D' ($x = 4$) $\longrightarrow (2 \times 4 + 1) \bmod 31 = 9 \longrightarrow$ 'I'
    Le message chiffré renvoyé est donc "CEGI".

4.3. Fonction de déchiffrement dechiff_affine(mess, a, b)

  • Résolution mathématique dans $\mathbb{Z}/31\mathbb{Z}$ :
    Comme $31$ est un nombre premier, $\mathbb{Z}/31\mathbb{Z}$ est un corps : tous les entiers $a \in \{1, \dots, 30\}$ sont premiers avec $31$ ($\operatorname{pgcd}(a, 31) = 1$) et admettent donc un inverse modulaire $a^{-1}$ modulo $31$.
    Pour retrouver la position initiale du caractère à partir de la position chiffrée $y$ : $$a \times position(caractere) + b \equiv y \pmod{31}$$ $$a \times position(caractere) \equiv y - b \pmod{31}$$ $$position(caractere) \equiv a^{-1} \times (y - b) \pmod{31}$$
  • Code Python : 
    def inverse_modulaire(a):
    for i in range(31):
        if (a * i) % 31 == 1:
            return i
    return None

def dechiff_affine(mess, a, b):
    res = ""
    inverseA = inverse_modulaire(a)
    for c in mess:
        if c in dico.keys():
            position = dico[c]
            newIndice = (inverseA * (position - b)) % 31
            res += dico_inverse[newIndice]
    return res

# Tests de vérification
message2 = "ABCD"
a = 2
b = 1
chiffre = chiff_affine(message2, a, b)
assert chiffre != message2
assert dechiff_affine(chiffre, a, b) == message2

4.5. Échange secret de la clé $(a, b)$ : Protocole de Diffie-Hellman

Pour échanger secrètement la clé $(a, b)$ sur un canal non sécurisé sans rencontre préalable, les deux correspondants (Alice et Bob) utilisent le protocole d'échange de clés de Diffie-Hellman, fondé sur la difficulté du logarithme discret :

  1. Paramètres publics : Alice et Bob conviennent publiquement d'un grand nombre premier $p$ et d'un entier générateur $g$ tel que $1 < g < p$.
  2. Choix des secrets privés : Chacun choisit un entier secret qu'il conserve privé : $x$ pour Alice, $y$ pour Bob.
  3. Calcul et envoi des clés publiques :
    • Alice calcule $A = g^x \pmod{p}$ et l'envoie à Bob.
    • Bob calcule $B = g^y \pmod{p}$ et l'envoie à Alice.
  4. Calcul du secret partagé : À réception, chacun élève la valeur reçue à la puissance de son propre secret :
    • Alice calcule : $S = B^x \pmod{p} = (g^y)^x \pmod{p} = g^{xy} \pmod{p}$
    • Bob calcule : $S = A^y \pmod{p} = (g^x)^y \pmod{p} = g^{xy} \pmod{p}$
    Ils obtiennent le même secret $S$ sans jamais l'avoir transmis sur le canal.
  5. Dérivation du couple $(a, b)$ : Pour obtenir deux entiers dans $\mathbb{Z}/31\mathbb{Z}$, Alice et Bob exécutent le protocole deux fois (avec deux paires de secrets) ou dérivent deux valeurs à partir de $S$ (par fonction de hachage), en veillant à ce que $a \in \{1, \dots, 30\}$ (inversible modulo $31$) et $b \in \{0, \dots, 30\}$.
Sécurité : Un espion interceptant $p$, $g$, $A$ et $B$ ne peut pas retrouver $x$ ni $y$ si $p$ est suffisamment grand, car résoudre $A \equiv g^x \pmod{p}$ (logarithme discret) est calculatoirement impraticable.

Chiffrement affine

Méthode de chiffrement par substitution monoalphabétique où chaque lettre de rang $x$ est transformée via une fonction affine $f(x) = (ax + b) mod n$, avec $\operatorname{pgcd}(a, n) = 1$.

Nombre premier et $\mathbb{Z}/p\mathbb{Z}$

Lorsque $p$ est premier (ici $p = 31$), tout entier non nul modulo $p$ est premier avec $p$. Ainsi, tous les éléments de $\{1, \dots, 30\}$ sont inversibles dans $\mathbb{Z}/31\mathbb{Z}$.

Inverse modulaire ($a^{-1}$)

Un entier $u$ tel que $a imes u \equiv 1 \pmod{n}$. Il permet d'annuler la multiplication par $a$ lors du déchiffrement.

Protocole de Diffie-Hellman

Méthode cryptographique inventée en 1976 permettant à deux personnes de générer un secret partagé sur un canal non sécurisé sans jamais transmettre ce secret directement.

Problème du logarithme discret

Étant donnés $g$, $p$ et $A \equiv g^x \pmod{p}$, il est facile de calculer $A$ à partir de $x$, mais extrêmement difficile de retrouver l'exposant $x$ à partir de $A$ lorsque $p$ est grand.

Les bases du langage Java

Passe la souris surTouche les termes soulignés en pointillé pour afficher leur définition.

0. Le cycle de vie d'un programme

  • Le fichier source : Un fichier texte contenant nos instructions (ex: Main.java).
  • La compilation : Un outil nommé javac traduit ce code en bytecode (un fichier Main.class).
  • L'exécution par la JVM : Cette machine virtuelle lit ce bytecode et le traduit à la volée pour ton système (Windows, Mac ou Linux).

1. La structure minimale

  • Le principe : En Java, tout le code s'écrit dans une classe.
  • Le fichier modèle : Le fichier porte exactement le même nom que la classe publique (ici Main.java).
  • Le code de démarrage : 
    public class Main {
    public static void main(String[] args) {
        System.out.println("Bonjour le monde !");
    }
}
  • Anatomie des mots-clés :
    • public : accessible depuis n'importe quelle autre classe.
    • static : la méthode s'appelle sans créer d'objet avant.
    • void : la méthode ne renvoie rien.
    • main(...) : le nom de la méthode que la JVM cherche pour lancer le programme.

2. Les variables et le typage statique

  • Le mécanisme : Java utilise un typage statique. Chaque variable déclare à l'avance le type de ce qu'elle contient.
  • Types primitifs (la valeur est stockée directement) :
    • int : stocke un nombre entier sans virgule (ex: int age = 25;).
    • double : stocke un nombre décimal à virgule (ex: double prix = 19.99;).
    • boolean : vaut true ou false.
    • char : un seul caractère, entre apostrophes (ex: char note = 'A';).
  • Types objets (la variable contient une référence vers l'objet) :
    • String : une chaîne de caractères entre guillemets (ex: String nom = "Alice";). Elle est immuable.

3. Boucles et conditions

  • Les conditions : 
    int score = 75;

if (score >= 50) {
    System.out.println("Réussi");
} else {
    System.out.println("Échoué");
}
  • Les boucles :
    • for : utilisée lorsqu'on connaît à l'avance le nombre d'itérations à effectuer. 
      for (int i = 0; i < 5; i++) {
    System.out.println("Tour n° " + i);
}
    • while : répète une tâche tant qu'une condition reste vraie.

4. La programmation orientée objet (POO) : classes, héritage et interfaces

  • Structure d'une classe : Une classe regroupe des attributs (variables) et des méthodes (actions). 
    public class Etudiant {
    // 1. Attributs privés (Encapsulation)
    private String nom;
    private int taille;

    // 2. Constructeur
    public Etudiant(String nom, int taille) {
        this.nom = nom;
        this.taille = taille;
    }

    public void signeSowesign() {
        System.out.println(this.nom + " a signé");
    }
}
  • Instanciation : On crée des objets à partir de la classe avec le mot-clé new. 
    Etudiant g1 = new Etudiant("Bruce", 165);
g1.signeSowesign();
  • L'encapsulation : Le mot private empêche le code des autres classes de modifier directement les données d'un objet.
  • L'héritage (extends) : Permet à une classe fille de récupérer tous les attributs et méthodes d'une classe mère pour les étendre ou les modifier. 
    // Classe Mère
public class Personne {
    protected String nom;
    public void respirer() { System.out.println("Je respire"); }
}

// Classe Fille qui hérite de Personne
public class Etudiant extends Personne {
    private int niveau;

    public Etudiant(String nom, int niveau) {
        this.nom = nom; // Hérité de Personne
        this.niveau = niveau;
    }
}
  • Les contrats et interfaces (implements) : Une interface est une liste de méthodes abstraites obligatoires. Une classe utilise implements pour s'engager à les coder. 
    public interface Travailleur {
    void travailler(); // Pas de corps, juste la signature
}

public class Developpeur implements Travailleur {
    @Override
    public void travailler() {
        System.out.println("Je code en Java !");
    }
}

6. Parcourir une structure de données

A. La boucle classique avec index

On utilise un compteur i, de 0 jusqu'à la taille de la liste, pour récupérer chaque élément par sa position.

List<String> prenoms = List.of("Alice", "Bob", "Charlie");

for (int i = 0; i < prenoms.size(); i++) {
    String prenom = prenoms.get(i); // Récupère l'élément à l'index i
    System.out.println("À l'index " + i + " : " + prenom);
}

B. La méthode forEach et les lambdas

Elle applique une instruction à chaque élément de la collection, sans compteur.

prenoms.forEach(prenom -> System.out.println("Bonjour " + prenom));

C. forEach sur une HashMap (dictionnaire)

Pour parcourir les paires clé/valeur :

Map<String, Double> prix = Map.of("Café", 1.50, "Thé", 2.00);

prix.forEach((nom, tarif) -> {
    System.out.println(nom + " coûte " + tarif + " €");
});

D. Iterator et Streams

  • L' Iterator : Utile si tu dois modifier ou supprimer des éléments pendant le parcours sans faire planter le programme. 
    List<Integer> notes = new ArrayList<>(List.of(8, 12, 15, 5));
Iterator<Integer> it = notes.iterator();

while (it.hasNext()) {
    if (it.next() < 10) {
        it.remove(); // Supprime proprement l'élément courant
    }
}
  • L'API Stream : Style fonctionnel pour filtrer et transformer les données en une seule ligne. 
    List<String> villes = List.of("Paris", "Lyon", "Marseille", "Lille");

villes.stream()
      .filter(v -> v.startsWith("L"))
      .forEach(System.out::println); // Affiche Lyon puis Lille

7. La gestion des erreurs (Exceptions)

Pour éviter qu'un programme ne plante brutalement lors d'un imprévu (fichier introuvable, division par zéro, etc.).

try {
    int resultat = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Erreur : Division par zéro impossible !");
} finally {
    System.out.println("Ce bloc s'exécute toujours (nettoyage, fermeture de fichier...).");
}

JVM (Java Virtual Machine)

Le logiciel qui exécute le bytecode Java, quel que soit le système d'exploitation (Windows, macOS, Linux).

  • C'est ce qui rend Java portable : pas besoin de réécrire le code selon la machine.

Compilation

La traduction du code source écrit par un humain en un format que la machine sait exécuter.

  • En Java, c'est le compilateur javac qui fait cette traduction.

Bytecode

Le langage intermédiaire produit par le compilateur Java (les fichiers d'extension .class).

  • Ni un humain ni le processeur ne le lisent directement : c'est la JVM qui l'exécute.

Classe

Le moule qui décrit ce que les objets auront (attributs) et sauront faire (méthodes).

  • Sans classe, impossible de fabriquer des objets ni d'écrire des instructions en Java.

Objet (ou instance)

Un exemplaire créé en mémoire à partir d'une classe.

  • Chaque objet possède ses propres valeurs pour ses attributs (ex: deux guerriers distincts avec des noms différents).

Typage statique

Le programmeur doit indiquer à l'avance le type de chaque variable.

  • Empêche par exemple de mettre du texte dans une variable prévue pour des nombres, ce qui évite beaucoup de bugs.

Immutabilité

Caractéristique d'une donnée qui ne peut plus être modifiée une fois écrite en mémoire.

  • Quand on manipule un String, Java crée un nouveau texte sans toucher à l'original.

Attribut (ou champ)

Une caractéristique ou variable interne qui décrit l'état d'un objet.

  • Exemple : la couleur d'une voiture, l'âge d'un utilisateur ou le solde d'un compte bancaire.

Méthode

Une action ou fonction qu'un objet est capable d'accomplir sur commande.

  • Exemple : freiner, calculer un résultat, ou afficher un message à l'écran.

Encapsulation

Le principe qui consiste à bloquer l'accès direct aux attributs d'un objet (avec private).

  • Oblige le reste du programme à passer par des méthodes contrôlées pour consulter ou modifier une donnée.

Héritage (extends)

Permet à une classe fille de récupérer automatiquement les attributs et méthodes d'une classe mère pour éviter de dupliquer le code.

Interface (implements)

Un contrat : la classe qui l'implémente doit écrire toutes les méthodes définies par l'interface.

ArrayList

Un tableau dynamique qui agrandit ou réduit automatiquement sa taille selon les besoins.

  • On ajoute et on supprime des éléments sans fixer de taille au départ.

HashMap

Une structure en paires clé-valeur (comme un annuaire où le nom est la clé et le numéro la valeur).

  • On retrouve une valeur directement par sa clé, sans parcourir toute la liste.

Méthode forEach()

Une méthode des collections Java qui applique une action (exprimée sous forme de fonction lambda) à chaque élément.

  • La boucle tient en une ligne.

Iterator

Un pointeur de parcours qui se déplace élément par élément dans une collection.

  • Permet de supprimer des éléments pendant la lecture sans faire planter le programme.

Stream (API)

Un tapis roulant de données sur lequel on applique des filtres et des transformations en chaîne.

  • Le traitement tient en quelques lignes.

Exception

Un événement d'erreur émis par le programme lorsqu'une situation anormale se produit.

  • Si elle n'est pas "attrapée" (catch), elle interrompt immédiatement l'exécution de l'application.

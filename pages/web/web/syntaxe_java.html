Les Fondations du Langage Java

Passez la souris sur les termes soulignés en bleu pour afficher leur vulgarisation sans jargon.

0. Le cycle de vie d'un programme

  • Le fichier source : Un fichier texte contenant nos instructions (ex: Main.java).
  • La compilation : Un outil nommé javac traduit nos mots humains en bytecode (un fichier Main.class).
  • L'exécution par la JVM : Cette machine virtuelle lit ce bytecode et le traduit instantanément pour votre système (Windows, Mac ou Linux).

1. La structure minimale

  • Le principe : En Java, aucun code ne peut flotter dans le vide. Tout bloc d'instruction doit obligatoirement résider au sein d'une classe.
  • Le fichier modèle : Le fichier doit porter rigoureusement le même nom que la classe publique (ici Main.java).
  • Le code de démarrage : 
    public class Main {
    public static void main(String[] args) {
        System.out.println("Bonjour le monde !");
    }
}
  • Anatomie des mots-clés :
    • public : accessible par tout le système.
    • static : la fonction peut démarrer immédiatement sans avoir besoin de fabriquer un objet au préalable.
    • void : indique que cette action accomplit une tâche sans renvoyer de résultat chiffré en retour.
    • main(...) : le nom conventionnel du sas de lancement recherché en priorité par la machine.

2. Les variables et le typage statique

  • Le mécanisme : Java utilise un typage statique. Chaque boîte mémoire doit déclarer à l'avance la nature exacte de ce qu'elle contiendra.
  • Types primitifs (valeurs brutes directes) :
    • int : stocke un nombre entier sans virgule (ex: int age = 25;).
    • double : stocke un nombre décimal à virgule (ex: double prix = 19.99;).
    • boolean : un interrupteur logique binaire, valant uniquement true ou false.
    • char : un caractère alphanumérique unique entre apostrophes simples (ex: char note = 'A';).
  • Types objets / références (structures élaborées) :
    • String : une chaîne de caractères entre guillemets (ex: String nom = "Alice";). Elle bénéficie du principe d'immutabilité.

3. Boucles et conditions

  • Les conditions : 
    int score = 75;

if (score >= 50) {
    System.out.println("Réussi");
} else {
    System.out.println("Échoué");
}
  • Les boucles :
    • for : utilisée lorsqu'on connaît à l'avance le nombre d'itérations à effectuer. 
      for (int i = 0; i < 5; i++) {
    System.out.println("Tour n° " + i);
}
    • while : répète une tâche tant qu'une condition reste vraie.

4. La Programmation Orientée Objet (POO), Classes, Héritage et Interfaces

  • L'architecture d'une classe : Une classe regroupe des attributs (variables) et des méthodes (actions). 
    public class Etudiant {
    // 1. Attributs privés (Encapsulation)
    private String nom;
    private int taille;

    // 2. Constructeur
    public Etudiant(String nom, int taille) {
        this.nom = nom;
        this.taille = taille;
    }

    public void signeSowesign() {
        System.out.println(this.nom + " a signé");
    }
}
  • Utilisation par instanciation : On crée des exemplaires distincts sur ce moule grâce au mot-clé new. 
    Etudiant g1 = new Etudiant("Bruce", 165);
g1.signeSowesign();
  • La protection par encapsulation : Le mot private empêche tout code extérieur de corrompre arbitrairement les données d'un objet.
  • L'héritage (extends) : Permet à une classe fille de récupérer tous les attributs et méthodes d'une classe mère pour les étendre ou les modifier. 
    // Classe Mère
public class Personne {
    protected String nom;
    public void respirer() { System.out.println("Je respire"); }
}

// Classe Fille qui hérite de Personne
public class Etudiant extends Personne {
    private int niveau;

    public Etudiant(String nom, int niveau) {
        this.nom = nom; // Hérité de Personne
        this.niveau = niveau;
    }
}
  • Les contrats et interfaces (implements) : Une interface est une liste de méthodes abstraites obligatoires. Une classe utilise implements pour s'engager à les coder. 
    public interface Travailleur {
    void travailler(); // Pas de corps, juste la signature
}

public class Developpeur implements Travailleur {
    @Override
    public void travailler() {
        System.out.println("Je code en Java !");
    }
}

5. Les structures de données (Collections Framework)

Java fournit un ensemble complet d'outils pour regrouper et organiser des données en mémoire.

Structure Type Caractéristiques principales
T[] (Tableau fixe) Tableau brut Taille fixe définie à la création, très performant.
ArrayList<E> Liste ordonnée Taille dynamique, doublons autorisés, accès rapide par index.
HashSet<E> Ensemble (Set) Pas de doublons, pas d'ordre garanti, recherches extrêmement rapides.
HashMap<K, V> Dictionnaire (Map) Paires Clé/Valeur, clés uniques, accès direct via la clé.

Exemples de déclaration :

// 1. Les Tableaux
int[] tableau = new int[5];
int[] notes = {10, 15, 12, 13, 16};
int[][] matrice = new int[3][3];

// 2. ArrayList de chaînes de caractères
List<String> fruits = new ArrayList<>();
fruits.add("Pomme");
fruits.add("Banane");

// 3. HashMap (Clé = ID / Valeur = Nom)
Map<Integer, String> utilisateurs = new HashMap<>();
utilisateurs.put(101, "Alice");
utilisateurs.put(102, "Bob");

6. Comment parcourir des structures de données (Du classique à l'amélioré)

A. La version normale (La boucle classique avec index)

C'est la méthode fondamentale : on utilise un compteur i (partant de 0 jusqu'à la taille de la liste) pour aller chercher chaque élément un par un via son numéro de position.

List<String> prenoms = List.of("Alice", "Bob", "Charlie");

for (int i = 0; i < prenoms.size(); i++) {
    String prenom = prenoms.get(i); // Récupère l'élément à l'index i
    System.out.println("À l'index " + i + " : " + prenom);
}

B. La version améliorée (La méthode forEach et Lambdas)

Plus moderne et concise, elle applique directement une instruction à chaque élément de la collection sans variable intermédiaire superflue.

prenoms.forEach(prenom -> System.out.println("Bonjour " + prenom));

C. Version améliorée pour une HashMap (Dictionnaire)

Pour parcourir des paires Clé/Valeur de manière moderne :

Map<String, Double> prix = Map.of("Café", 1.50, "Thé", 2.00);

prix.forEach((nom, tarif) -> {
    System.out.println(nom + " coûte " + tarif + " €");
});

D. Les versions expertes : Iterator et Streams

  • L' Iterator : Utile si vous devez modifier ou supprimer des éléments en plein milieu du parcours sans faire planter le programme. 
    List<Integer> notes = new ArrayList<>(List.of(8, 12, 15, 5));
Iterator<Integer> it = notes.iterator();

while (it.hasNext()) {
    if (it.next() < 10) {
        it.remove(); // Supprime proprement l'élément courant
    }
}
  • L'API Stream : Style fonctionnel très élégant pour filtrer et transformer les données en une seule ligne. 
    List<String> villes = List.of("Paris", "Lyon", "Marseille", "Lille");

villes.stream()
      .filter(v -> v.startsWith("L"))
      .forEach(System.out::println); // Affiche Lyon puis Lille

7. La gestion des erreurs (Exceptions)

Pour éviter qu'un programme ne plante brutalement lors d'un imprévu (fichier introuvable, division par zéro, etc.).

try {
    int resultat = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("Erreur : Division par zéro impossible !");
} finally {
    System.out.println("Ce bloc s'exécute toujours (nettoyage, fermeture de fichier...).");
}

JVM (Java Virtual Machine)

C'est un logiciel intermédiaire qui sert d'émulateur universel. Il exécute le bytecode Java quel que soit le système d'exploitation hôte (Windows, macOS, Linux).

  • Garantit la portabilité : aucun besoin de réécrire le code selon la machine.

Compilation

L'opération de traduction intégrale d'un texte écrit par un humain vers un dialecte condensé et optimisé que la machine sait exploiter.

  • En Java, c'est le compilateur javac qui effectue ce passage vers le fichier binaire.

Bytecode

Le langage intermédiaire produit par le compilateur Java (les fichiers d'extension .class).

  • Il n'est pas lisible par un humain ni directement par le processeur, mais spécifiquement par la JVM.

Classe

Le moule de fabrication ou la notice technique qui liste ce que posséderont et sauront faire les objets qui en découleront.

  • Sans classe, impossible de fabriquer des objets ni d'écrire des instructions en Java.

Objet (ou Instance)

Une entité vivante en mémoire, créée d'après le plan d'une classe.

  • Chaque objet possède ses propres valeurs pour ses attributs (ex: deux guerriers distincts avec des noms différents).

Typage statique

Une règle stricte qui oblige le programmeur à définir à l'avance le genre d'information qu'une variable recevra.

  • Empêche de mettre du texte dans une case prévue pour des calculs numériques, limitant drastiquement les bugs.

Immutabilité

Caractéristique d'une donnée qui ne peut plus jamais être modifiée une fois écrite en mémoire.

  • Quand on manipule un String, Java fabrique un nouveau texte sans jamais altérer l'original.

Attribut (ou Champ)

Une caractéristique ou variable interne qui décrit l'état d'un objet.

  • Exemple : la couleur d'une voiture, l'âge d'un utilisateur ou le solde d'un compte bancaire.

Méthode

Une action ou fonction qu'un objet est capable d'accomplir sur commande.

  • Exemple : freiner, calculer un résultat, ou afficher un message à l'écran.

Encapsulation

Un principe de sécurité consistant à verrouiller l'accès direct aux entrailles d'un objet (via private).

  • Oblige le reste du programme à passer par des méthodes contrôlées pour consulter ou modifier une donnée.

Héritage (extends)

Permet à une classe fille de récupérer automatiquement les attributs et méthodes d'une classe mère pour éviter de dupliquer le code.

Interface (implements)

Contrat technique strict que s'engage à respecter une classe en écrivant obligatoirement les méthodes définies par l'interface.

ArrayList

Un tableau dynamique qui agrandit ou réduit automatiquement sa taille selon les besoins.

  • Permet d'ajouter/supprimer des éléments facilement sans préciser de taille fixe au départ.

HashMap

Une structure en paires Clé-Valeur (comme un annuaire où le nom est la clé et le numéro la valeur).

  • Permet de retrouver une donnée instantanément sans parcourir toute la liste.

Méthode forEach()

Une méthode intégrée aux collections Java qui applique une action (exprimée sous forme de fonction lambda) à chaque élément.

  • Permet d'écrire des boucles ultra-courtes et très lisibles.

Iterator

Un pointeur de parcours qui se déplace élément par élément dans une collection.

  • Permet de supprimer des éléments pendant la lecture sans faire planter le programme.

Stream (API)

Un tapis roulant de données sur lequel on applique des filtres et des transformations en chaîne.

  • Permet d'écrire du code de traitement très court, lisible et performant.

Exception

Un événement d'erreur émis par le programme lorsqu'une situation anormale se produit.

  • Si elle n'est pas "attrapée" (catch), elle interrompt immédiatement l'exécution de l'application.

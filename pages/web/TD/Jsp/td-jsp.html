Chapitre 3 : les JSP

Passe la souris surTouche les termes soulignés en pointillé pour afficher leur définition.

1. Toutes les balises d'une page JSP

  • Principe : une JSP est une page HTML dans laquelle on glisse des balises spéciales. À la première requête, le conteneur la transforme en servlet (puis la compile), et c'est cette servlet qui répond ensuite.
  • Les familles : éléments de script (<% %>), directives (<%@ %>), actions standard (<jsp:... />), EL (${ }) et JSTL (<c:... >).
BaliseNomÀ quoi ça sertExemple
Éléments de script
<% ... %> Scriptlet Code Java exécuté à chaque requête (placé dans _jspService() de la servlet générée). Les variables déclarées ici sont locales à la requête. <% int n = 5; %>
<%! ... %> Déclaration Déclare une variable d'instance ou une méthode, au niveau de la classe. Une variable déclarée ainsi est partagée entre tous les utilisateurs. <%! private int compteur = 0; %>
<%= ... %> Expression Évalue une expression Java et affiche le résultat dans la page. Équivaut à out.print(...), sans point-virgule. <%= compteur %>
<%-- ... --%> Commentaire JSP Supprimé côté serveur, donc invisible dans le HTML reçu (contrairement à <!-- -->). <%-- à corriger --%>
Directives (lues à la compilation de la page)
<%@ page ... %> Directive page Configure la page : import, contentType, pageEncoding, errorPage, isErrorPage, session, isELIgnored... <%@ page import="java.util.List" contentType="text/html;charset=UTF-8" %>
<%@ include file="..." %> Inclusion statique Insère le contenu d'un fichier à la compilation, avant la génération de la servlet. <%@ include file="header.jsp" %>

Note : l'URI de la JSTL core est jakarta.tags.core avec Tomcat 10 et plus, et http://java.sun.com/jsp/jstl/core avec les anciennes versions (Java EE).

2. Les objets implicites utilisables dans les scriptlets

  • Principe : ces objets existent déjà dans la servlet générée, on les utilise directement sans les déclarer (ce sont les mêmes que ceux manipulés dans les servlets du chapitre 2).
ObjetTypeÀ quoi ça sertExemple
requestHttpServletRequestLa requête : paramètres, headers, attributs de requête.request.getParameter("nom")
responseHttpServletResponseLa réponse : redirection, cookies, headers.response.sendRedirect("login.jsp")
sessionHttpSessionLa session de l'utilisateur.session.setAttribute("user", u)
applicationServletContextDonnées partagées par toute l'application.application.getAttribute("compteur")
outJspWriterÉcrit dans la réponse (comme le PrintWriter d'une servlet).out.println("Salut")
configServletConfigParamètres d'initialisation de la page.config.getInitParameter("type")
pageContextPageContextAccès à tous les scopes et aux autres objets implicites.pageContext.getAttribute("x")
pageObjectLa servlet générée elle-même (équivalent de this), rarement utilisé.<%= page.getClass().getName() %>
exceptionThrowableL'erreur reçue, disponible uniquement si isErrorPage="true".<%= exception.getMessage() %>

3.1.1. HelloWorld

Fichier : webapp/JSP/HelloWorld/helloWorld.jsp

  • <%@ ... %> : directive JSP qui donne des instructions au conteneur web lors de la traduction/compilation de la page JSP en servlet.
  • <%@ page ... %> : directive de page permettant de configurer les propriétés globales de la JSP (type MIME de la réponse avec contentType, encodage avec pageEncoding, importation de classes Java avec import, etc.).
  • <%! ... %> : déclaration JSP permettant de déclarer des attributs (variables d'instance) ou des méthodes directement au niveau de la classe de la servlet générée (en dehors de _jspService()).
  • <% ... %> : scriptlet JSP contenant des instructions Java exécutées à chaque requête HTTP au sein de la méthode _jspService().
  • <%= ... %> : expression JSP qui évalue une expression Java et insère directement sa valeur convertie en chaîne de caractères dans le flux de sortie HTML (équivalent à out.print(...), sans point-virgule final).
  • out : objet implicite de type jakarta.servlet.jsp.JspWriter permettant d'écrire du contenu textuel dans le flux de réponse envoyé au navigateur (équivalent au PrintWriter dans une servlet classique).
<%@ page contentType="text/html; charset=UTF-8" pageEncoding="UTF-8" %>
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Hello World JSP</title>
</head>
<%! String text = "Hello Worldddddddddddddddd!"; %>
<body>
<h1>
<%--
    <%
      out.println(text);
    %>
--%>
    <%
    for(int i = 0;i < 10 ; i++){
         out.println(text);
    }
    %>

</h1>
<!-- Alternative plus courte via une expression JSP -->
<p><%= text %></p>
</body>
</html>

3.1.3 & 3.1.4. Afficher un tableau de produits depuis un DAO via une servlet et gérer les quantités (MVC)

Fichiers utilisés :

  • Modèle & DAO : java/products/dao/Product.java, java/products/dao/optional/Dao.java, java/products/dao/optional/ProductMemoryDao.java
  • Contrôleur : java/products/controller/ProductController.java (mappé sur /products/products_controller)
  • Vue : webapp/JSP/Products/productsMVC.jsp
  • Initialisation & GET (3.1.3) : dans init(ServletConfig config), ProductController peuple le ProductMemoryDao. Lors d'un doGet, il récupère dao.getAll(), le place dans la requête avec request.setAttribute("produits", produits) et effectue un forward vers /JSP/Products/productsMVC.jsp.
  • POST & Redirection (3.1.4) : chaque ligne du tableau possède deux formulaires POST (actions add et subtract avec un champ hidden pour l'id). Le doPost met à jour la quantité via le DAO puis redirige en GET avec response.sendRedirect(request.getContextPath() + "/products/products_controller").

Contrôleur (ProductController.java) :

package products.dao.controller;

import jakarta.servlet.ServletConfig;
import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.HttpServlet;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import products.dao.Product;
import products.dao.optional.Dao;
import products.dao.optional.ProductMemoryDao;

import java.io.IOException;
import java.util.List;
import java.util.Optional;

@WebServlet(name = "ProductController",value = "/products/products_controller")
public class ProductController extends HttpServlet {

    private Dao<Product> dao = new ProductMemoryDao();

    @Override
    public void init(ServletConfig config) throws ServletException {
        super.init(config);
        dao.save(new Product(1, "Ordinateur", 750.0, 10));
        dao.save(new Product(2, "Clavier", 35.0, 25));
        dao.save(new Product(3, "Souris", 20.0, 50));
        dao.save(new Product(4, "Écran", 180.0, 8));
    }

    @Override
    public void doGet(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException{
        List<Product> produits = dao.getAll();
        request.setAttribute("produits", produits);
        request.getRequestDispatcher("/JSP/Products/productsMVC.jsp")
                .forward(request, response);
    }

    @Override
    public void doPost(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException{
        int id = Integer.parseInt(request.getParameter("id"));
        String action = request.getParameter("action");

        ProductMemoryDao productDao = (ProductMemoryDao) dao;
        Optional<Product> product = productDao.get(id);

        if(action.equals("add")){
            if(product.isPresent()){
                product.get().setQuantity(product.get().getQuantity()+1);
                productDao.save(product.get());
            }
        } else if (action.equals("subtract")) {
            if(product.isPresent()){
                int quantity = product.get().getQuantity() - 1;
                if (quantity >= 0) {
                    product.get().setQuantity(quantity);
                    productDao.save(product.get());
                }
            }
        }
        response.sendRedirect(
                request.getContextPath() + "/products/products_controller"
        );
    }
}

Contrôleur (AuthenticateMvc.java) :

package iut.nantes.session.mvcAuthenticate;

import jakarta.servlet.ServletException;
import jakarta.servlet.annotation.WebServlet;
import jakarta.servlet.http.*;

import java.io.IOException;

@WebServlet(name="JspSessionAuthenticate",value="/mvcAuthenticate/session-authenticate")
public class AuthenticateMvc extends HttpServlet {
    @Override
    public void doGet(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException{
        authenticate(request,response);

    }

    @Override
    public void doPost(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException{
        authenticate(request,response);
    }

    public void authenticate(HttpServletRequest request, HttpServletResponse response) throws IOException {
        String login = request.getParameter("login");
        String password = request.getParameter("password");

        if(!login.equals("JoJo") || !password.equals("JoJo44")){
            String referer = request.getHeader("Referer");
            if(referer != null){
                response.sendRedirect(referer);
            }else {
                response.sendRedirect("index.jsp");
            }
            return;
        }
        Cookie cookieLogin = new Cookie("login",login);
        cookieLogin.setMaxAge(60*60);
        cookieLogin.setPath("/");

        response.addCookie(cookieLogin);
        response.setContentType("text/html;charset=UTF-8");

        HttpSession session = request.getSession();
        session.setAttribute("login",login);

        response.sendRedirect("/demo/JSP/Session/sessionPrivate.jsp");
    }
}

JSP (JavaServer Pages)

Une page web dynamique qui mélange du HTML et des balises Java. Elle est traduite automatiquement en servlet par le conteneur.

  • Elle sert surtout à la vue (l'affichage).

Conteneur web

Le moteur qui crée les servlets, appelle leurs méthodes et gère leur cycle de vie. Ici, c'est Tomcat.

EL (Expression Language)

Un petit langage, écrit entre ${ }, pour lire des données (attributs, paramètres, propriétés d'objets) directement dans une JSP.

JSTL

La bibliothèque standard de balises pour les JSP : conditions, boucles, formatage... Elle remplace le code Java des scriptlets.

  • Elle s'importe avec la directive taglib.

JavaBean

Une classe Java simple avec un constructeur sans paramètre, des attributs privés et des getters / setters.

Scope (portée)

La durée de vie d'une donnée :

  • page : cette page seulement
  • request : le temps d'une requête
  • session : tant que l'utilisateur est connecté
  • application : toute l'application, pour tous les utilisateurs

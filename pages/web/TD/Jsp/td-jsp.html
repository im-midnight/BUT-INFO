Chapitre 3 : les JSP

Passe la souris surTouche les termes soulignés en pointillé pour afficher leur définition.

1. Toutes les balises d'une page JSP

  • Principe : une JSP est une page HTML dans laquelle on glisse des balises spéciales. À la première requête, le conteneur la transforme en servlet (puis la compile), et c'est cette servlet qui répond ensuite.
  • Les familles : éléments de script (<% %>), directives (<%@ %>), actions standard (<jsp:... />), EL (${ }) et JSTL (<c:... >).
BaliseNomÀ quoi ça sertExemple
Éléments de script
<% ... %> Scriptlet Code Java exécuté à chaque requête (placé dans _jspService() de la servlet générée). Les variables déclarées ici sont locales à la requête. <% int n = 5; %>
<%! ... %> Déclaration Déclare une variable d'instance ou une méthode, au niveau de la classe. Une variable déclarée ainsi est partagée entre tous les utilisateurs. <%! private int compteur = 0; %>
<%= ... %> Expression Évalue une expression Java et affiche le résultat dans la page. Équivaut à out.print(...), sans point-virgule. <%= compteur %>
<%-- ... --%> Commentaire JSP Supprimé côté serveur, donc invisible dans le HTML reçu (contrairement à <!-- -->). <%-- à corriger --%>
Directives (lues à la compilation de la page)
<%@ page ... %> Directive page Configure la page : import, contentType, pageEncoding, errorPage, isErrorPage, session, isELIgnored... <%@ page import="java.util.List" contentType="text/html;charset=UTF-8" %>
<%@ include file="..." %> Inclusion statique Insère le contenu d'un fichier à la compilation, avant la génération de la servlet. <%@ include file="header.jsp" %>

Note : l'URI de la JSTL core est jakarta.tags.core avec Tomcat 10 et plus, et http://java.sun.com/jsp/jstl/core avec les anciennes versions (Java EE).

2. Les objets implicites utilisables dans les scriptlets

  • Principe : ces objets existent déjà dans la servlet générée, on les utilise directement sans les déclarer (ce sont les mêmes que ceux manipulés dans les servlets du chapitre 2).
ObjetTypeÀ quoi ça sertExemple
requestHttpServletRequestLa requête : paramètres, headers, attributs de requête.request.getParameter("nom")
responseHttpServletResponseLa réponse : redirection, cookies, headers.response.sendRedirect("login.jsp")
sessionHttpSessionLa session de l'utilisateur.session.setAttribute("user", u)
applicationServletContextDonnées partagées par toute l'application.application.getAttribute("compteur")
outJspWriterÉcrit dans la réponse (comme le PrintWriter d'une servlet).out.println("Salut")
configServletConfigParamètres d'initialisation de la page.config.getInitParameter("type")
pageContextPageContextAccès à tous les scopes et aux autres objets implicites.pageContext.getAttribute("x")
pageObjectLa servlet générée elle-même (équivalent de this), rarement utilisé.<%= page.getClass().getName() %>
exceptionThrowableL'erreur reçue, disponible uniquement si isErrorPage="true".<%= exception.getMessage() %>

JSP (JavaServer Pages)

Une page web dynamique qui mélange du HTML et des balises Java. Elle est traduite automatiquement en servlet par le conteneur.

  • Elle sert surtout à la vue (l'affichage).

Conteneur web

Le moteur qui crée les servlets, appelle leurs méthodes et gère leur cycle de vie. Ici, c'est Tomcat.

EL (Expression Language)

Un petit langage, écrit entre ${ }, pour lire des données (attributs, paramètres, propriétés d'objets) directement dans une JSP.

JSTL

La bibliothèque standard de balises pour les JSP : conditions, boucles, formatage... Elle remplace le code Java des scriptlets.

  • Elle s'importe avec la directive taglib.

JavaBean

Une classe Java simple avec un constructeur sans paramètre, des attributs privés et des getters / setters.

Scope (portée)

La durée de vie d'une donnée :

  • page : cette page seulement
  • request : le temps d'une requête
  • session : tant que l'utilisateur est connecté
  • application : toute l'application, pour tous les utilisateurs

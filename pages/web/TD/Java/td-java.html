1. Gestion des Étudiants

  • Classes et Héritage : Implémentation d'une classe Etudiant caractérisée par un numéro et une moyenne, et d'une classe fille EtudiantAvecEtatMental incluant un état mental via une énumération.
  • Encapsulation et Collections : La classe Promotion gère une liste d'étudiants, calcule la moyenne globale et lève des exceptions en cas de doublons ou d'erreurs.

Code : Promotion

package promotion;

import java.util.ArrayList;

public class Promotion {

    private ArrayList etudiants = new ArrayList();

    public int getNombreEtudiants(){
        return etudiants.size();
    }

    public void ajouterEtudiant(Etudiant etu){
        if(!etudiants.contains(etu)){
            if(etu == null || this.contientEtudiant(etu.getNo())){
                throw new IllegalArgumentException();
            }
            this.etudiants.add(etu);
        }
        else{
            throw new IllegalArgumentException();
        }
    }

    public boolean supprimerEtudiant(String etu){
        for(int i = 0 ;i < etudiants.size();i++){
            if(etu == this.etudiants.get(i).getNo()){
                this.etudiants.remove(this.etudiants.get(i));
                return true;
            }
        }
        return false;
    }

    public ArrayList getEtudiants(){
        return etudiants;
    }

    public boolean contientEtudiant(String etu){
        for(int i = 0 ;i < etudiants.size();i++){
            if(etu == this.etudiants.get(i).getNo()){
                return true;
            }
        }
        return false;
    }

    public double moyenne(){
        if (this.etudiants.size() == 0){
            return 0;
        }
        int notes =0;
        for(int i = 0 ;i < this.etudiants.size();i++){
            notes += this.etudiants.get(i).getMoyenne();
        }
        return (double) notes/this.etudiants.size();
    }
}

2. Pattern DAO : Approche Classique

  • Principe : Permet d'isoler l'accès aux données (ici en mémoire via une HashMap).
  • Gestion des erreurs : Utilisation d'exceptions de type IllegalArgumentException si un élément n'existe pas ou si les paramètres sont invalides.

Code : ProductMemoryDao

package dao.old;

import dao.Product;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class ProductMemoryDao implements Dao {

    private Map storage = new HashMap();

    @Override
    public Product get(long id) {
        if ( id < 0 || id >= storage.size()) throw new IllegalArgumentException();
        return storage.get(id);
    }

    @Override
    public List getAll() {
        List res = new ArrayList<>();
        storage.forEach((code, produit) -> {
            res.add(produit);
        });
        return res;
    }

    @Override
    public void update(Product o, String[] params) {
        if(params == null || params.length != 4 || !storage.containsKey(Long.parseLong(params[0]))) throw new IllegalArgumentException();

        long keyProduitUpdate = o.getId();
        Integer id = Integer.parseInt(params[0]);
        String name = params[1];
        Double price = Double.parseDouble(params[2]);
        Integer quantity = Integer.parseInt(params[3]);

        Product updatedProduct = new Product(id, name, price, quantity);

        storage.replace(keyProduitUpdate,updatedProduct);
    }

    @Override
    public void delete(Product o) {
        if (o == null) throw new IllegalArgumentException();

        long key = o.getId();
        if (!storage.containsKey(key)) throw new IllegalArgumentException();

        storage.remove(key);
    }


    @Override
    public void save(Product o) {
        if( o == null) throw new IllegalArgumentException();
        long key = o.getId();
        storage.put(key,o);
    }
}

3. Pattern DAO : Approche Optional

  • Sécurité anti-null : Introduction des Optional en Java 8 pour éviter les NullPointerException de manière fonctionnelle.
  • Signature de méthode : La méthode get(long id) renvoie un Optional<T> au lieu de risquer de retourner null.

Code : ProductMemoryDaoOptional

package dao.optional;

import dao.Product;

import java.util.*;

public class ProductMemoryDaoOptional implements Dao {

    private Map storage = new HashMap<>();

    @Override
    public Optional get(long id) {
        return Optional.ofNullable(storage.get(id));
    }

    @Override
    public List getAll() {
        List res = new ArrayList<>();
        storage.forEach((code, produit) -> {
            res.add(produit);
        });
        return res;
    }

    @Override
    public void update(Product o, String[] params) {
        if(params == null || params.length != 4 || !storage.containsKey(Long.parseLong(params[0]))) throw new IllegalArgumentException();

        long keyProduitUpdate = o.getId();
        Integer id = Integer.parseInt(params[0]);
        String name = params[1];
        Double price = Double.parseDouble(params[2]);
        Integer quantity = Integer.parseInt(params[3]);

        Product updatedProduct = new Product(id, name, price, quantity);

        storage.replace(keyProduitUpdate,updatedProduct);
    }

    @Override
    public void delete(Product o) {
        if (o == null) throw new IllegalArgumentException();

        long key = o.getId();
        if (!storage.containsKey(key)) throw new IllegalArgumentException();

        storage.remove(key);
    }


    @Override
    public void save(Product o) {
        if( o == null) throw new IllegalArgumentException();
        long key = o.getId();
        storage.put(key,o);
    }
}

Classe Etudiant

Classe de base contenant un numéro unique (no) et une moyenne flottante (moyenne par défaut à 10.0).

Héritage et Extension

Permet à une classe fille (ex: EtudiantAvecEtatMental) de réutiliser les attributs et méthodes de la classe mère via le mot-clé extends

Promotion

Structure regroupant les étudiants dans une ArrayList, avec des règles de gestion strictes (interdiction d'ajouter deux fois le même numéro).

HashMap

Structure de données clé-valeur idéale en mémoire pour implémenter rapidement un DAO sans base de données relationnelle.

Optional<T>

Conteneur d'objet qui peut contenir ou non une valeur non nulle. Permet d'éviter proprement les erreurs de type NullPointerException.
